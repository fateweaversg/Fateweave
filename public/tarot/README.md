# Rider–Waite Major Arcana — Tarot Card Images

Real card artwork for the FateWeave tarot readings (22 major arcana only).
Source: the original 1909 Rider–Waite deck, illustrated by Pamela Colman Smith (1878–1951),
from Wikimedia Commons. All 22 files were individually verified as public domain before download.

## Processing

- Downloaded the full-resolution Commons scans (approx. 1110 × 1920 px, 736 KB–1.18 MB each).
- Downscaled with Python PIL (Lanczos) to 600 px wide, JPEG quality 85, to keep every file under 500 KB. No upscaling.
- Every downloaded file was validated as JPEG image data (`file` + PIL open/verify).
- Spot-checked visually: 00-fool.jpg (The Fool, dog and cliff), 13-death.jpg (Death, skeleton on white horse),
  16-tower.jpg (The Tower, lightning-struck tower), 21-world.jpg (The World, dancing figure in wreath) — all correct.

Total size of the 22 images: 4,958,176 bytes (4842.0 KB / 4.73 MB).
Cards that could NOT be verified as public domain: none — all 22 verified.
